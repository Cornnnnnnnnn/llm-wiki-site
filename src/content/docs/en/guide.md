## Start with a note

Keep originals outside the website. Use a provided template to create a private draft. Verify notation, formulas, and source pages; flag uncertainty with `[UNCLEAR: reason; source p.N]`. Review content before deciding whether to authorize publication.

## Three publication gates

Only articles with `visibility: public`, `status: reviewed`, and an explicitly approved allowlist entry appear. Search, tags, backlinks, and the graph share this public catalog. Original files require separate permission; original previews are currently disabled.

## Mathematics and provenance

Use `$...$` for inline math and `$$...$$` for display math. Cite source pages near important claims. Copy LaTeX buttons preserve the formula source.

## Confirm connections

Add only human-confirmed article IDs to `related`. Relations appear only when both articles are public. Shared tags never create automatic edges.

## Browse and search

Filter by subject, type, or tag, or search full text. Language controls change interface labels while preserving article language. Theme preferences remain on your device. Git and deployment remain manual.
