## 從第一篇筆記開始

1. 將原始文件保留在網站目錄之外的私人資料夾。
2. 使用專案的手寫筆記、論文筆記或數位筆記模板建立私人草稿。
3. 核對內容、公式和來源頁碼。以 `[UNCLEAR: 原因; source p.N]` 標記不確定處。
4. 完成你的內容審閱，另外決定哪些文章可以公開。
5. 只有獲得公開許可的文章，才可移入網站並登錄公開清單。

## 公開文章的三個條件

文章必須同時具備 `visibility: public`、`status: reviewed`，以及明確的公開清單登錄。沒有核准的內容不會出現在搜尋、標籤或圖譜中。

原始 PDF 與圖片需要另外獲得公開許可。目前原始文件預覽維持關閉；網站不會連結電腦上的私人檔案。

## 公式與來源

行內公式使用 `$...$`，獨立公式使用 `$$...$$`。重要推論與公式應在附近標記來源頁碼。「複製 LaTeX」按鈕可複製公式原文。

## 建立連結

只有你確認的文章 ID 才可放進 `related`。公開關聯圖只顯示兩端均已公開的連結；相同標籤不會自動產生關係。

## 介面與搜尋

首頁提供文章類型、學科、標籤與全文搜尋。EN 按鈕切換介面語言；文章保留原文。太陽圖示切換明暗模式，偏好僅儲存在本機。

網站不會自動提交、推送或部署。
